# CapsSwitcher

Маленькая программа для Windows 10/11: набрали текст не в той раскладке — нажмите **F1**, и он превратится в правильный.

```
Ghbdtn? rfr ltkf&   →  F1  →  Привет, как дела?
руддщ цщкдв         →  F1  →  hello world
```

- Работает в фоне, значок **EN/RU** в трее.
- Запускается вместе с Windows.
- Ничего дополнительно ставить не нужно, права администратора не нужны.

## Установка (и переустановка после смены системы)

**Вариант 1 — одной командой.** Откройте PowerShell и вставьте:

```powershell
irm https://raw.githubusercontent.com/Yury93/caps-switcher/main/install.ps1 | iex
```

**Вариант 2 — из архива.** Скачайте репозиторий (Code → Download ZIP), распакуйте и дважды кликните `install.cmd`.

Установщик собирает программу встроенным в Windows компилятором .NET Framework, кладёт её в
`%LOCALAPPDATA%\CapsSwitcher`, добавляет в автозагрузку и сразу запускает. Повторный запуск установщика
обновляет программу.

Удаление: `uninstall.cmd`.

## Как пользоваться

| Ситуация | Что делает F1 |
|---|---|
| Текст выделен | Переключает выделенный текст |
| Ничего не выделено | Переключает всё от курсора до начала поля ввода |

- Направление (рус → англ или англ → рус) определяется автоматически по тому, каких букв больше.
- После исправления раскладка окна тоже переключается — можно сразу печатать дальше.
- Ещё раз F1 (или Ctrl+Z) — вернуть как было.
- Содержимое буфера обмена после работы восстанавливается.

Меню по правому клику на значке в трее: включить/выключить, **выбор клавиши** (F1, F2, F12, Pause/Break,
Scroll Lock, Shift+F1, Ctrl+Shift+Space, Alt+Shift+Space), автозапуск, выход. Выбранная клавиша запоминается.
Двойной клик по значку — быстро включить/выключить (значок становится серым).

## Ограничения

- Выбранная клавиша перехватывается глобально (например, «Справка» по F1 в других программах работать не будет).
  Если мешает — выберите другую в меню «Клавиша».
- На ноутбуках F1 может управлять яркостью/звуком — тогда нажимайте Fn+F1 или выберите другую клавишу.
- Программа работает через Ctrl+C / Ctrl+V, поэтому в окнах, где копирование и вставка запрещены, она не сработает.
- В окнах, запущенных от администратора, программа работает, только если её тоже запустить от администратора.
